# Shared assignment and finding contracts

This is a **semantic agreement for real Codex agents**, not a parser, orchestration service, security boundary or mandate for verbose forms. The existing [debate rules](debate-rules.md) govern actual delivery/response receipts; [evidence policy](evidence-policy.md) governs empirical claims.

## Assignment (CIO or authorized Dev Studio coordinator)

Give the selected specialist a bounded brief with: session/department/mode; question and decision affected; exact task authority; source artifacts and versions; relevant exclusions for independence; expected output; available tools, access and research budget; edit ownership; stopping criteria. Omit inapplicable optional fields and state unavailable capabilities. **Do not equate being asked to read a path with successful file access.** If worker cannot open required instructions, supply actual appropriate text and disclose the constraint.

For independent R1 research, exclude earlier candidate solutions from Inventor's context. For SPEC*REVIEW, all recipients examine the \_same frozen normative revision* and the prior decision state; do not send biased desired verdicts.

## Consequential finding

Minimal fields where material: `finding_id`, `session_round`, `department/role`, `actual_runtime_identity_if_available`, `claim_or_objection`, `impacted_idea_or_requirement`, `evidence_refs`, `claim_class`, `confidence_and_reason`, `counterevidence`, `decision_impact`, `open_question`, `proposed_next_action`.

Keep VERIFIED / INFERENCE / HYPOTHESIS / UNKNOWN canonical. Other classification dimensions (OBSERVED_BEHAVIOR, SPECIFICATION_DEFECT, DOCS_VERIFIED) do not replace claim class. Preserve per-agent original output, even when summarizing. No invented runtime/message identities.

## Real exchange

Identify original finding ID, critic identity, recipient identity, exact objection, delivery receipt or preserved payload, actual recipient response, proponent reply, assessment before/after, unresolved issue and version impact. Track PREPARED / SENT / RESPONDED / FAILED_OR_UNKNOWN separately. **SENT is not RESPONDED**, nor is a coordinator paraphrase an independent agent reply. If the runtime cannot deliver/collect, report partial or BLOCKED_MULTI_AGENT rather than simulating a council.

## Scope and editing

Specialists return findings or write a uniquely owned notes file. CIO owns R&D synthesis and shared portfolio writes; BA owns draft normative requirements during authorized Product Definition; Dev Studio reviewers do not edit R&D's specification without its owner. Use the existing portfolio write lock for shared R&D portfolio state. No automatic build, deployment or product decision.

## Efficient operation

Use compact structured summaries and hyperlinks to source receipts, not copied transcripts. Call only agents whose expertise materially affects the decision; when mode requires full peer + Red Team evidence, distinguish a partial task from a completed council. Halt repetitive debate once further exchanges cannot change the judgment.
